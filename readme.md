# Чат с Yandex AI Studio

Консольный Python-клиент для общения с моделью Яндекса через API. Выводит ответы, время выполнения и расход токенов. Сохраняет лог в `chat.log`.

## Установка

Работа клиента тестировалась на python 3.12

В папке проекта создайте виртуальное окружение и установите зависимости.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip -r requitements.txt
```

## Настройки

Значения переменных находятся в файле `.env`:


| Параметр                   | Назначение                             |
| -------------------------- | -------------------------------------- |
| `YANDEX_API_KEY`           | API-ключ Яндекса                       |
| `YANDEX_FOLDER_ID`         | Идентификатор каталога Yandex Cloud    |
| `YANDEX_MODEL`             | Выбранная модель                       |
| `YANDEX_TEMPERATURE`       | Температура генерации                  |
| `YANDEX_MAX_OUTPUT_TOKENS` | Максимальное число выходных токенов    |
| `YANDEX_TOP_P`             | Параметр вероятностного отбора токенов |


Замените значения в квадратных скобках файла `.env` своими данными. Не публикуйте API-ключ.

При необходимости откорректируйте `prompt.txt` (кодировка UTF-8). Пример  системного промпта:

```text
Ты — помощник по программированию. Отвечай на русском.
```

После изменения настроек или промпта перезапустите программу.

## Запуск

```powershell
python main.py
```

Введите вопрос и нажмите Enter. Для выхода введите `0`.

Каждый вопрос отправляется независимо: история предыдущих сообщений модели не передаётся. RAG и поиск по документам не используются.

## Логирование

Файл `chat.log` создаётся рядом с программой и дополняется при каждом запуске. В него записываются:

- Дата и время запуска.
- Модель и системный промпт.
- Вопросы и ответы.
- Время полного ответа.
- Параметры, возвращённые API.
- Расход токенов, если статистика доступна.
- Сообщения о незавершённом ответе.
